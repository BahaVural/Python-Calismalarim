# Python Çalışmalarım

Üniversitede Python öğrenirken yaptığım küçük uygulamaları ve algoritma alıştırmalarını bu depoda topladım. Dosyalar derslerde ve kendi çalışmalarım sırasında yazdığım orijinal kodlardır.

## Mini Uygulamalar

- **ATM (`atm.py`):** Para çekme, para yatırma ve bakiye sorgulama işlemleri.
- **TV ve Projeksiyon (`classodev.py`):** Sınıflar, metotlar ve kalıtım kullanarak hazırladığım kumanda uygulaması.
- **Telefon Rehberi (`kayit.py`):** Kullanıcıdan bilgi alıp metin dosyasına kayıt ekleme ve kayıtları listeleme.

## Algoritma Alıştırmaları

- **Fibonacci:** Fibonacci dizisini ekrana yazdırma.
- **Faktöriyel:** Girilen sayının faktöriyelini hesaplama.
- **Mükemmel Sayı:** Bir sayının mükemmel sayı olup olmadığını kontrol etme.
- **Küçük Sayı:** Üç sayıyı karşılaştırma alıştırması.
- **3'e Bölünebilen Sayılar:** 1 ile 99 arasındaki 3'e bölünebilen sayıları listeleme.

## Kullanılan Teknoloji

- Python 3

## Çalıştırma

Dosyalar terminal üzerinden `python dosya_adi.py` komutuyla çalıştırılabilir. Ek bir kütüphane kurulumu gerekmiyor. Dosyaları kendi klasörleri içerisinden çalıştırabilirsin.

Bu depo, temel Python konularında yaptığım eğitim çalışmalarını saklamak amacıyla hazırlanmıştır. Bazı alıştırmalarda eksikler bulunabilir; üretim ortamına yönelik uygulamalar değildir.
